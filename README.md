# benjaminlindeen.com

Personal portfolio website built with Next.js, TypeScript, and Tailwind CSS. Deployed on Vercel.

[![Next.js](https://skillicons.dev/icons?i=nextjs,typescript,tailwind,vercel)](https://skillicons.dev)

## Stack

- **Framework:** Next.js 16 (App Router, fully static)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** lucide-react
- **Deployment:** Vercel

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Push to GitHub and import the repo in [vercel.com](https://vercel.com). Vercel auto-detects Next.js and deploys on every push to `main`.
